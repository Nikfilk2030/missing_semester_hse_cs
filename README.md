# Missing Semester · Инструменты промышленной разработки

Здесь собраны конспекты семинаров, примеры для разбора и домашние задания

## Что разбираем

| Тема | На практике |
|---|---|
| Терминал и shell | Находить нужное в файлах и логах, соединять команды через pipe, автоматизировать рутину скриптами |
| Git | Работать с ветками, разбирать конфликты, читать историю и восстанавливать изменения |
| Окружение и сборка | Разбираться в зависимостях и пакетах, понимать, что нужно для запуска проекта на другой машине |
| Отладка | Ставить точки останова, смотреть состояние программы и искать причину ошибки с помощью `pdb` |
| Open source | Читать лицензии и понимать, на каких условиях можно использовать чужой код |
| Markdown и LaTeX | Писать понятную документацию, набирать формулы и оформлять отчёты |

На семинарах запускаем команды, читаем исходники и документацию, разбираем ошибки. В домашних заданиях пробуем те же инструменты самостоятельно.

## Как ориентироваться

Материалы сгруппированы по году, направлению и курсу. В каталогах занятий лежат конспекты и примеры, домашние работы вынесены отдельно. Нужный раздел можно открыть через список каталогов репозитория.
